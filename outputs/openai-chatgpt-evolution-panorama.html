04 / Models

模型谱系：从单一旗舰到分层家族

“ChatGPT”是产品；GPT、o、Codex、Image、Realtime / Live 等是模型或模型家族。产品可能路由多个模型并叠加工具、记忆与安全层。

GPT 主线

GPT-1 建立“预训练 + 微调”，GPT-2 引入分阶段发布，GPT-3 把提示学习推向平台，GPT-4 强化可靠性与多模态，GPT-4o 统一文本、视觉与音频。

推理与分层

o1 将“思考时间”产品化；GPT-5 以后逐步形成 Instant / Thinking / Pro、mini / nano 及 Sol / Luna / Astra 等按能力、速度和成本分层的家族。

专用模型

Codex 面向软件工程；GPT Image / DALL·E 面向图像；Whisper、Realtime 与 GPT-Live 覆盖转写和实时语音；Sora 面向视频。

05 / ChatGPT

从聊天窗口到个人与组织工作平台

功能并非一次到位，而是沿对话、感知、检索、创作、记忆、协作和执行逐层叠加。

能力层代表节点产品变化
对话与个性化ChatGPT、Custom Instructions、Memory从单轮问答到跨对话连续性
感知与创作Vision、Voice、Images、Canvas文本窗口扩展为多模态创作空间
检索与研究Search、Deep Research、Shopping Research从回答已有知识到检索、引用和综合
组织工作Team/Business、Enterprise、Projects、Workspace Agents从个人工具到受治理的团队平台
执行任务Tasks、Operator、Agent、Apps从建议到调用工具和完成多步骤工作
智能界面GPT-6 与 Intelligent UI界面开始按任务动态组织信息和操作
06 / API & Agents

接口范式从“生成文本”转向“完成任务”

开发者平台把消息、结构化输出、工具、检索、计算机使用、MCP、追踪和托管运行逐步组合为代理基础设施。

2020—2023

  • 托管 GPT-3 API
  • Chat Completions 与角色消息
  • Function Calling 与 Assistants API

2024—2025

  • Structured Outputs 与 Realtime API
  • Responses API、Web/File Search、Computer Use
  • Agents SDK、MCP 与后台任务

2026

  • Agents API 承担更完整的部署和持续执行
  • GPT-Live-1 API 提供更自然实时语音
  • GPT-6 家族强化代理、工具和智能界面
07 / Codex

从代码生成模型到多代理工程环境

Codex 的主语逐渐从“模型”变成“产品系统”：本地 CLI、云端沙箱、桌面指挥中心、跨设备任务、代码审查和安全分析。

阶段代表节点核心形态
代码模型2021 OpenAI Codex自然语言转代码与 Codex API
本地代理Codex CLI在代码库中读取、修改、运行命令
云端代理2025 Codex隔离环境并行执行任务与测试
工程环境Codex App、跨设备工作多任务、工作树、技能与远程延续
质量与安全代码审查、Codex Security从产出代码扩展到验证与漏洞分析
前沿模型GPT-5.x-Codex、GPT-6专用编码优化与通用旗舰能力并行
08 / Multimodal

图像、语音、视频走向原生统一

早期是独立模型串联；GPT-4o、Realtime 和 GPT-Live 逐步把理解、生成与实时互动放进更统一的架构。

媒介演进路线关键转变
图像DALL·E → DALL·E 2/3 → 4o Image → ChatGPT Images 2.0从单次生成到对话式编辑和创作工作流
语音Whisper → ChatGPT Voice → Realtime → GPT-Live从级联系统到原生、连续、全双工交互
视频Sora 研究预览 → Sora 产品 → Sora 2从演示世界模型到带音频的可控创作产品
视觉理解GPT-4 Vision → GPT-4o → 推理模型看图图像从输入附件变为推理和代理上下文

10 / Pricing

ChatGPT 订阅与 API 用量计费必须分开看

订阅购买产品体验和额度，API 则按实际调用单位计费。缓存、Batch、优先处理、地区和第三方云都会改变成本。

计费体系主要单位关键提醒
ChatGPT 订阅按用户/周期购买产品访问与额度；不等于 API 余额
API 标准按 token、图像、音频或工具调用输入、缓存输入、输出通常分别计费
Batch / Flex以当前 API 价格页为准用延迟或调度换取成本差异
Realtime / 媒体按音频、文本或生成单位实时语音与图像/视频不是统一 token 单价
第三方云由合作云厂商定价Azure 等渠道与 OpenAI 直连价格可能不同

官方入口：API Pricing。本页不硬编码易过期的 token 单价。

11 / Migration

“最新”不等于“直接替换”

模型别名、接口范式、工具行为和产品路由会同时变化。迁移要依靠评测，而不是只改一个模型字符串。

迁移主题变化实践提醒
Completions → Chat Completions接口从单段补全转向角色化消息检查提示结构与旧模型弃用日期
Assistants → Responses / Agents工具、状态与代理运行逐步统一按官方迁移指南迁移线程、工具和存储
Preview → 固定快照/正式版预览别名可能滚动更新生产环境记录模型 ID 与评测基线
ChatGPT 模型 ≠ API 模型同名体验可能含路由、工具和系统层不要把产品行为直接等同于裸 API
订阅 ≠ API 计费ChatGPT 计划不自动包含 API 用量分别查看 ChatGPT 与 Platform 账单
12 / Inflection points

六个战略转折

把离散发布放回长期轨迹，能看到 OpenAI 产品方向如何从模型能力扩展到工作流和界面。

① 预训练成为通用底座

任务专用训练转向大规模预训练，再通过提示、微调或对齐适配。

② 从补全到遵循意图

InstructGPT 与 ChatGPT 把 RLHF、对话和用户意图放到核心。

③ 模型进入产品层

ChatGPT 用订阅、工具、企业工作区和移动端把模型变成持续服务。

④ 原生多模态

图像、语音和视频不再只是外围工具，而是统一交互的一部分。

⑤ 推理与代理

o 系列、Responses、Operator、Deep Research 和 Agent 把输出从答案推进到行动。

⑥ 智能工作界面

Codex、Workspace Agents 与 Intelligent UI 让系统围绕任务动态组织工具和界面。
