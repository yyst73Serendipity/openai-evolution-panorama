# OpenAI 产品与模型演进全景 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建覆盖 2015-12 至 2026-10-20、可每日自动更新并发布到 GitHub Pages 的 OpenAI 产品与模型单文件中文全景网页。

**Architecture:** 以 `timeline-data.json` 为单一事实源，Python 标准库构建器完成校验、统计和 HTML 生成；独立更新器从 OpenAI 官方 sitemap、Release Notes、定价和弃用页面发现变化，并用可审计状态文件去重。GitHub Actions 串行执行抓取、构建、测试、提交和 Pages 发布，任何失败都保留上一版站点。

**Tech Stack:** Python 3.12 标准库、原生 HTML5/CSS3/JavaScript、`unittest`、Node.js `--check`、GitHub Actions、GitHub Pages。

**Spec:** `docs/superpowers/specs/2026-10-20-openai-evolution-panorama-design.md`

## Global Constraints

- 交互文案与项目文档使用中文；文件名使用 kebab-case，Python 文件顶部使用中文多行注释。
- 首版数据范围为 2015-12 至 2026-10-20；后续只收录不晚于北京时间检查日的官方事件。
- 官方来源主机仅允许 `openai.com`、`www.openai.com`、`help.openai.com`、`developers.openai.com`、`platform.openai.com`、`learn.chatgpt.com` 及明确配置的官方 X 页面。
- 最终网页为一个纯前端 HTML；CSS、JavaScript 和数据全部内嵌，不依赖 CDN、外部字体、外部脚本或运行时网络请求。
- 自动收录不得推断官方未明示的性能、价格或可用性；必须带 `autoGenerated: true` 和 `verification: "自动收录"`。
- 新增第三方依赖为零；测试使用 Python 标准库，JavaScript 语法用系统 Node.js 检查。
- 所有外链使用 HTTPS、`target="_blank"` 和 `rel="noopener noreferrer"`。
- 支持 320px 宽度、键盘操作、跳过链接、`aria-live`、打印样式、深浅主题和 `prefers-reduced-motion`。
- 每项实现先写失败测试并验证 RED，再写最小实现并验证 GREEN。
